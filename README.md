# Get Us There

Get Us There is the World of Warcraft 3.3.5a companion addon for the
**Get Us There** AzerothCore server module.

**Server module:** https://github.com/apw1963/mod-get-us-there

The addon provides the player-facing search and teleport interface. Destination
availability, policy, safety checks, and teleport authorization remain
server-authoritative.

## Requirements

- World of Warcraft 3.3.5a
- AzerothCore server running the matching Get Us There server module

## Installation

Copy this repository folder into the WoW client as:

`Interface/AddOns/GetUsThere`

The folder should contain:

- `GetUsThere.toc`
- `GetUsThere.lua`

Start or reload the client, then enter:

`/gut`

to open Get Us There.
